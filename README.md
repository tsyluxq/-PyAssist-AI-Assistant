# 🤖 PyAssist AI Assistant

PyAssist is a simple command-line AI-style assistant built with Python. 🐍💻 It allows users to interact with the program by entering commands and receiving predefined responses.

💬 The assistant can respond to greetings, provide a basic explanation of Python, perform simple calculations, and exit the program when requested. If an unknown command is entered, PyAssist informs the user that the command is not currently supported.

🛠️ This project demonstrates fundamental Python concepts such as functions, loops, conditional statements, user input, string manipulation, and program control.

🚀 PyAssist is designed as a beginner-friendly project and can be expanded in the future with more commands, advanced calculations, file handling, APIs, natural language processing, and other AI-related features.

✨ The project represents a simple first step toward building a more advanced personal AI assistant.
